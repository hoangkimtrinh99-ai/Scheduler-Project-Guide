⚠️ Troubleshooting

If videos don't show:

  1. Check if videos are set to "Public" or "Unlisted" (not Private)
  2. In YouTube Studio, go to each video's settings
  3. Under "Visibility" → Make sure it's not "Private"
  4. Under "Advanced settings" → Check "Allow embedding" is enabled
  5. Some browsers may block iframes - try a different browser
  6. Check if you have any ad blockers that might block YouTube embeds
