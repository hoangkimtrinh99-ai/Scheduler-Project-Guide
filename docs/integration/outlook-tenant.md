# Outlook Integration (Tenant)

This guide will walk you through setting up Outlook integration for the tenant, allowing all appointments to be synced with the tenant's Outlook calendar.

## Overview

Tenant-level Outlook integration enables:

- Automatic sync of all appointments to the tenant's Outlook calendar
- Real-time updates when appointments are created, modified, or cancelled
- Centralized calendar management for the organization

## Setup Outlook Integration (Tenant)

### Step 1: Navigate to Integrations
- In the left-hand side menu, navigate to **Settings** → **Integrations**
- Click **Edit** on the Outlook integration option

![Outlook Tenant 1](../image/outlook%20tenant%201.png)

### Step 2: Connect Outlook
- Click **Connect Outlook**
- You will be redirected to Microsoft Outlook authentication page

![Outlook Tenant 2](../image/outlook%20tenant%202.png)

### Step 3: Complete Authentication

- Sign in with your Microsoft account
- Grant necessary permissions for calendar access
- Confirm the integration request

## What Gets Synced

### Appointment Details
- Appointment date and time
- Customer information
- Service details
- Staff member assigned
- Branch location
- Appointment status (confirmed, cancelled, completed)

### Calendar Events
- All appointments appear as calendar events
- Events include all relevant appointment details
- Real-time updates when appointments change

## Troubleshooting

**Cannot see Integrations menu**: Ensure you have admin permissions to access integration settings.

**Authentication fails**: Check your Microsoft account credentials and permissions.

**Sync not working**: Verify internet connection and try reconnecting Outlook.

**Missing appointments**: Check that appointments are being created properly in the scheduler system.

**Permission errors**: Ensure the Microsoft account has appropriate calendar access permissions.
