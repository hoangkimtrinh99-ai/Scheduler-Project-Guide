# 📋 Pre-criteria

## Overview

Before setting up the Scheduler system, ensure the following prerequisites are met. This step is crucial for a successful setup process.

---

## ✅ Required Prerequisites

**1. Tenant Setup (CRS):** The tenant must already be set up

**2. Branch Creation:** At least one branch must already be created in the system

**3. Admin Access:** Admin user must be able to log in to the admin portal

---

## 🚀 Next Steps

Once all prerequisites are verified, proceed with the scheduler setup.
