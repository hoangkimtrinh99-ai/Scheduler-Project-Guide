# Setup Branch Equipment

This guide will walk you through adding equipment to your branch in the scheduler system.

## Overview

Branch equipment represents the physical resources available in your branch. Each equipment item must be assigned an equipment type that was previously created in the Rooms & Equipment settings.

## Setup Branch Equipment

### Step 1: Navigate to Branch Settings
In the left-hand side menu, navigate to **Settings** → **Branch**

### Step 2: Select Branch
Click ![Edit](../image/Edit%20pencil.png) to **view the branch**

![Edit Brand Hour 1](../image/Edit%20brand%20hour%201.png)

### Step 3: Access Equipment Section
- In the branch view, locate the **Equipments** section
- Click **Create Equipment**

![Create Branch Equipment 1](../image/Create%20brach-equip%201.png)

### Step 4: Input Equipment Details
- **Name**: Enter a descriptive name for the equipment
- **Description (Optional)**: Enter a description of the equipment's features or specifications
- **Photo (Optional)**: Upload a photo of the equipment
- **Equipment Type**: Select the appropriate equipment type from the dropdown (created in previous setup)
- **Quantity**: Set the quantity (you can leave this as 1 for individual items)

![Create Branch Equipment 2](../image/Create%20brach-equip%202.png)

### Step 5: Save Equipment
- Click **Create** to add the equipment
- Make sure to click the **Save** button in the bottom right corner

## Next Steps

## Troubleshooting

**Cannot see Equipments section**: Ensure you're in the correct branch view and have admin permissions.

**No equipment types available**: Complete the [Rooms & Equipment setup](rooms-equipment.md) first.

**Equipment not saving**: Verify all required fields are filled and click the main "Save" button after creating equipment.
