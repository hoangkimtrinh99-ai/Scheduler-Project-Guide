# Setup Rooms & Equipment Types

This guide will walk you through setting up room and equipment types in the scheduler system.

## Overview

Room and equipment types are templates that define the categories of rooms and equipment available in your system. These types are used when creating actual rooms and equipment for specific branches.

## Setup Room Types

### Step 1: Navigate to Settings
In the left-hand side menu, navigate to **Settings** → **Rooms & Equipments**

### Step 2: Select Rooms Tab
Click on the **Rooms** tab below the main menu

![Create Room - Step 1](../image/Create%20Room%201.png)

### Step 3: Create Room Type

- **Name**: Enter a descriptive name for the room type
- **Description (Optional)**: Enter a description explaining the room type's purpose
- Click **Create**

![Create Room - Step 2](../image/Create%20Room%202.png)

## Setup Equipment Types

### Step 1: Navigate to Settings
In the left-hand side menu, navigate to **Settings** → **Rooms & Equipment**

### Step 2: Select Equipment Tab
Click on the **Equipment** tab below the main menu

![Create Equipment - Step 1](../image/Create%20Equipment%201.png)

### Step 3: Create Equipment Type
Click **Create** button and fill in the following information:
- **Name**: Enter a descriptive name for the equipment type
- **Description(Optional)**: Enter a description explaining the equipment type's purpose
- Click **Create**

![Create Equipment - Step 2](../image/Create%20Equipment%202.png)
