# Setup Branch Operating Hours

This guide will walk you through setting up the operating hours for your branch in the scheduler system.

## Overview

Branch operating hours define when your branch is open for business. These hours are used to:

- Determine available appointment slots
- Set staff availability windows
- Control when services can be booked

## Setup Branch Operating Hours

### Step 1: Navigate to Branch Settings
In the left-hand side menu, navigate to **Settings** → **Branch**

### Step 2: Select Branch
Click ![Edit](../image/Edit%20pencil.png) to **view the branch**

![Edit Brand Hour 1](../image/Edit%20brand%20hour%201.png)

### Step 3: Set Operating Hours
In the **Operating Hours** section, you need to setup the operating hours for each day from Monday to Sunday

### Step 4: Set Daily Hours
- Click on each **Day** (Monday through Sunday)
- Use the **time slider** to set the opening and closing times for each day
- You can set different hours for each day of the week
- Click **Save Changes** after setting hours for each day

![Edit Brand Hour 2](../image/Edit%20brand%20hour%202.png)

![Edit Brand Hour 3](../image/Edit%20brand%20hour%203.png)

### Step 5: Save All Changes
After setting up hours for all days, make sure to click the **Save** button in the bottom right corner

![Edit Brand Hour 4](../image/Edit%20brand%20hour%204.png)

## Time Slider Usage

### Setting Opening Time
- Drag the left handle of the time slider to set when the branch opens
- The time will be displayed as you drag

### Setting Closing Time
- Drag the right handle of the time slider to set when the branch closes
- Ensure closing time is after opening time

### Closed Days
- To set a day as closed, click the **time slider** and deactivate that day
- Click **Save Changes** after setting

![Deactivate Sunday Brand Hours](../image/Deactive%20sunday%20brand%20hrs.png)

## Troubleshooting

**Time slider not responding**: Try refreshing the page and ensure you have admin permissions.

**Cannot save changes**: Verify that closing time is after opening time for each day.

**Hours not displaying correctly**: Check that you've clicked "Save Changes" for each day and the main "Save" button.

**Multiple branches**: Repeat this process for each branch that needs different operating hours.
