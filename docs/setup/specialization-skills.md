# Setup Specialization & Skills (Optional)

This guide covers the optional setup of specializations and skills for staff members in the scheduler system.

## Overview

Specializations and skills allow you to categorize staff members based on their expertise and capabilities. This helps in:

- Matching staff to appropriate services
- Filtering staff availability based on service requirements
- Organizing staff by their areas of expertise

## Setup Specializations

### Step 1: Navigate to Settings
In the left-hand side menu, navigate to **Settings** → **Specialization & Skills**

### Step 2: Select Specialization Tab
Click on the **Specialization** tab below the main menu

![Create Specialization - Step 1](../image/Create%20specialization%201.png)

### Step 3: Create Specialization
- **Name**: Enter a descriptive name for the specialization
- **Description (Optional)**: Enter a description explaining the specialization
- Click **Create Specialization**

![Create Specialization - Step 2](../image/Create%20specialization%202.png)

## Setup Skills

### Step 1: Navigate to Settings
In the left-hand side menu, navigate to **Settings** → **Specialization & Skills**

### Step 2: Select Skills Tab
Click on the **Skills** tab below the main menu

![Create Skill - Step 1](../image/Create%20Skill%201.png)

### Step 3: Create Skill
- **Name**: Enter a descriptive name for the skill
- **Description (Optional)**: Enter a description explaining the skill
- Click **Create Skill**

![Create Skill - Step 2](../image/Create%20Skill%202.png)
