# Setup Staff Shift Template

This guide will walk you through creating staff shift templates that define standard working patterns for your staff members.

## Overview

Staff shift templates are predefined work schedules that can be applied to staff members

## Setup Staff Shift Template

### Step 1: Navigate to Branch Settings
In the left-hand side menu, navigate to **Settings** → **Branch**

### Step 2: Select Branch
Click ![Edit](../image/Edit%20pencil.png) to **view the branch**

![Edit Brand Hour 1](../image/Edit%20brand%20hour%201.png)

### Step 3: Access Staff Shift Template Section
- In the **Operating Hours** section, locate the **Staff Shift Template** section
- Click **Create Template**

![Create Staff Shift Template 1](../image/Create%20Staff%20shift%20template%201.png)

### Step 4: Fill In Template Details
- Fill in the template information:
    - **Name**: Enter a descriptive name for the shift template
- Use the **time slider** to set:
    - Available Times
    - Break Times

![Create Staff Shift Template 2](../image/Create%20Staff%20shift%20template%202.png)

### Step 5: Save Template
- Click **Add** to create the template
- Make sure to click the **Save** button in the bottom right corner

## Time Slider Usage

### Available Times
- Set the shift pattern for staff

### Break Times
- Define break periods within the available times
- Staff will not be available for appointments during break times
- You can set multiple break periods if needed

## Troubleshooting

**Cannot see Staff Shift Template section**: Ensure you're in the correct branch view and have admin permissions.

**Time slider issues**: Try refreshing the page and ensure break times are within available times.

**Template not saving**: Verify all required fields are filled and click the main "Save" button after creating templates.

**Multiple branches**: Create shift templates for each branch that has different operational needs.
