# Setup Service Category

This guide will walk you through creating service categories to organize your services in the scheduler system.

## Overview

Service categories help customers to find the services they need and for staff to manage service offerings.

## Setup Service Category

### Step 1: Navigate to Services
- In the left-hand side menu, navigate to **Services** → **Category**
- Click **Create Categories**

![Create Category 1](../image/create%20cat%201.png)

### Step 2: Input Category Details

- **Name**: Enter a descriptive name for the service category
- **Description (Optional)**: Enter a description explaining what services fall under this category

![Create Category 2](../image/create%20cat%202.png)

### Step 3: Save Category
Click **Create** to add the category

## Next Steps

After setting up service categories, proceed to: [Setup Service](service.md)

## Troubleshooting

**Cannot see Services menu**: Ensure you have admin permissions to access services configuration.

**Category not saving**: Verify all required fields are filled and try again.
