# Setup Branch Room

This guide will walk you through adding rooms to your branch in the scheduler system.

## Overview

Branch rooms are the physical spaces where appointments take place. Each room must be assigned a room type that was previously created in the Rooms & Equipment settings.

## Setup Branch Room

### Step 1: Navigate to Branch Settings
In the left-hand side menu, navigate to **Settings** → **Branch**

### Step 2: Select Branch
Click ![Edit](../image/Edit%20pencil.png) to **view the branch**

![Edit Brand Hour 1](../image/Edit%20brand%20hour%201.png)

### Step 3: Access Rooms Section
- In the branch view, locate the **Rooms** section
- Click **Create Room**

![Create Room Name 1](../image/Create%20room%20name%201.png)

### Step 4: Input Room Details

- **Name**: Enter a descriptive name for the room
- **Description (Optional)**: Enter a description of the room's features or purpose
- **Room Type**: Select the appropriate room type from the dropdown (created in previous setup)

![Create Room Name 2](../image/Create%20room%20name%202.png)

### Step 5: Save Room
- Click **Create** to add the room
- Make sure to click the **Save** button in the bottom right corner

## Next Steps

After setting up branch rooms, proceed to: [Setup Branch Equipment](branch-equipment.md)

## Troubleshooting

**Cannot see Rooms section**: Ensure you're in the correct branch view and have admin permissions.

**No room types available**: Complete the [Rooms & Equipment setup](rooms-equipment.md) first.

**Room not saving**: Verify all required fields are filled and click the main "Save" button after creating rooms.
